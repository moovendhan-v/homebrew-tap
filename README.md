# moovendhan-v/homebrew-tap

Homebrew casks by [moovendhan-v](https://github.com/moovendhan-v).

## DevSweep

Developer-focused Mac cleaner: caches, system junk, large files, duplicates and unused apps.

```bash
brew trust --cask moovendhan-v/tap/devsweep
brew install --cask moovendhan-v/tap/devsweep
```
